**Git** is a distributed 
Version Control System that 
tracks changes to files via commits. 
Each developer maintains the repository 
and its history locally.

---

Its model revolves around a few key concepts: **Commits** represent changes, **branches** allow independent lines of development, and **merge** or **rebase** allow these to be integrated.

```text
Working Directory → Staging Area → Commit → Repository
```

> [!tip]
> Git is not just a tool for uploading code. Its main function is to **model and navigate a project’s change history**.

This is where [[julzdao/computer-science/Git Workflow]], [[julzdao/computer-science/Git Remote]], Git Stash and the various Git branching strategies come into play.

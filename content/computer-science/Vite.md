It is designed to make web development faster and smoother than older ways like Webpack. 

## Why is Vite powerful 

1. **Instant Server Start**: It makes serves the application in a faster way by only loading and requesting the specific modules needed on demand. 
2. **Fast Hot Module Replacement**: Similar to a modular application, when a change is made on a module, it only changes and updates that module, without needing to compile the whole bundle.
3. **Optimised Builds**: Following modern standards, the build has been optimised for maximum performance.
